# examples/ — 成品样例

> 这 7 份是**真实交付过的**官网价采集结果，不是编造的模板。
> 用途：做新任务时对照「目标长什么样」，尤其是格式细节与粒度判断。
> 打开任一份，重点看 **① 表头是否 8 列 ② 型号名称里发动机怎么并 ③ 燃油分类取值 ④ 千分位写法**。

## 一眼对照

| 文件 | 市场 | 条数 | 粒度 | 这份示例专门要你看什么 |
|---|---|---|---|---|
| `Mercedes-Benz_UK_官网价_20261020.xlsx` | 英国 | **403** | 变体级 | **规模上限长什么样**；同一车系燃油版与纯电版**同名**时怎么拆（`CLA` vs `CLA Electric`、`GLC` vs `GLC Electric`、`G-Class` vs `G-Class Electric`）；PHEV 多达 74 条 |
| `Skoda_UK_官网价_20261020.xlsx` | 英国 | 133 | 变体级 | **年款可以全量明确**：整批 `MY2027`；汽油 67 / 纯电 26 / 柴油 21 / **轻混 15** / 插混 4，是「五种动力并存」的典型 |

## 从这几份能确认的四条硬规则

**1. 固定 8 列，没有第九列**

```
品牌 | 官网车型名称 | 官网型号名称 | 年款 | 官网MSRP | 是否停销 | 数据日期 | 燃油分类
```

发动机/动力/变速箱/驱动**全部并入「官网型号名称」**，绝不单独建列。

**2. 型号名称用官网原始写法，不翻译**

```
✔ Puma | Titanium 1.0L EcoBoost Hybrid (mHEV) 125PS 6-speed Manual
✔ 208  | GT ELECTRIC 51kWh 156 7.4kW Charger
✔ 911  | 911 Carrera
✘ DUSTER | DUSTER expression | 三擎混动 150 4x4        ← 发动机单独列 + 中文翻译
```

官网写 `4*4` 就写 `4*4`，不改成 `4x4`。

**3. 年款只有两种取值：官网标了 → 原样写；没标 → `官网无年款`**

不许按新闻、按常识、按「应该是」推断。
- `Skoda_UK` 全 133 条 `MY2027`（配置器 modelId 第 3 段确认）
- `Mercedes-Benz_UK` 全 403 条 `官网无年款`（接口里的 `modelYear` 是 `804`/`056` 这种销售代码，不是年份）
- `Cadillac_US` 三代并列，因为官网配置器确实同时卖三个年款

**4. 千分位按市场原生写法，MSRP 单元格设为文本**

| 市场 | 写法 | 示例 |
|---|---|---|
| 欧元区 / 部分欧洲 | 点号千分位 | `28.220,00` |
| 英国 / 美国 | 逗号千分位 | `31,870` / `105,595` |
| 印度 | lakh 分组 | `2,11,29,000` |
| 泰国 / 韩国 | 逗号千分位 | `1,229,000` / `36,170,000` |

**不要为了统一而改成本地习惯**——这些是各市场官网的原生写法，改了就无法回溯核对。

## 反面教材（这些**没有**放进 examples）

| 情况 | 为什么不能这样 |
|---|---|
| 把「促销价」当 MSRP | Ford UK 的 `/cars` 页写 `Promotional Price`，比官方 PDF 低 1,000–4,750；必须采 PDF 的 OTR |
| 把「税制优惠后价」当 MSRP | KGM 韩国写 `시작가격 ...부터(세제혜택 후)`，是扣了购置税的价，要取 API/PDF 的原价 |
| 把 `totalAmount` 当 MSRP | Stellantis 系要取 `catalogAmount`（未折扣目录价） |
| 把颜色加价当成型号 | Toyota 印度 `[Platinum White Pearl]` 是车漆 +20,000，不是配置差异（146 条里剔掉 68 条） |
| 把 EMI 月供当成车价 | 印度 `₹39,999` 常是月供 |
| 只有一个 `from £X` 却硬凑出变体 | 官网公开粒度到哪就交到哪，`Hyundai_UK` 17 条就是正确交付 |
